# Introdução

Funções são blocos de código reutilizáveis que executam uma tarefa específica.

Elas ajudam a **organizar o código, evitar repetição, facilitar manutenção e tornar programas mais legíveis**.

Em Python, funções são fundamentais e aparecem em praticamente todo código profissional.

---
# Definição de Funções

Em Python, funções são definidas com a palavra-chave `def`.

## Sintaxe básica

```python
def nome_da_funcao():
	# bloco de código
	pass
```

## Exemplo Simples

```python
def saudacao():
	print("Olá, bem-vindo ao Python!")
```

Para executar a função:

```python
saudacao()
```

---
# Parâmetros de Funções

Parâmetros que você passe dados para a função.

## 1. Parâmetro simples

```python
def saudacao(nome):
	print(f"Olá, {nome}!")
	
saudacao("Maria")
```

**Saída:**

```text
Olá, Maria!
```

## 2. Múltiplos parâmetros

```python
def soma(a, b):
	print(a + b)
```

## 3. Parâmetros com valor padrão

```python
def saudacao(nome="usuário"):
	print(f"Olá, {nome}!")
```

---
# Retorno de Valores (`return`)

O comando `return` permite que a função devolva um valor.

## Exemplo

```python
def some(a, b):
	return a + b
	
resultado = soma(2, 3)
print(resultado)
```

## Retorno múltiplo (tupla)

```python
def calculos(a, b):
	return a + b, a * b
```

---
# Escopo de Variáveis

Escopo define, **onde uma variável pode ser acessada**.

## 1. Variáveis locais

```python
def exemplo():
	x = 10 # variável local
	print(x)
```

> `x` só existe dentro da função.

## 2. Variáveis globais

```python
x = 5

def exemplo():
	print(x)
```

## 3. Palavra-chave `global`

```python
contador = 0

def incrementar():
	global contador
	contador += 1
```

>[!warning] Atenção:
>Uso excessivo de `global` **não é recomendado**.

# Docstrings

Docstrings são **strings de documentação** usadas para explicar o que a função faz.

Elas aparecem logo abaixo da definição da função e usam strings multilinha.

## Exemplo de Docstring

```python
def soma(a, b):

"""
Soma dois números.

Parâmetros:
a (int | float): primeiro número
b (int | float): segundo número

Retorna:
int | float: resultado da soma
"""

return a + b
```

## Acessando a docstring

```python
print(soma.__doc__)
```

Ou usando

```python
help(soma)
```

---
# Boas Práticas com Funções

- Funções devem fazer **uma coisa só**
- Use nomes claros e descritivos
- Evite funções muito longas
- Sempre documente funções importantes

---
# Erros Comuns

❌ Esquecer de chamar a função
❌ Confundir `print` com `return`
❌ Usar muitas variáveis globais

---
# Casos de Uso Práticos

Funções são usadas para:

- Validação de dados
- Reutilização de lógica
- Organização de projetos
- Automação e scripts

Funções são a base para escrever código limpo, reutilizável e profissional em Python.
